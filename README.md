# StealEggs3D — Unity Prototype Starter

This repository contains the first **offline prototype** for a 3D egg-stealing game. It is not a finished multiplayer game.

## Open the project
1. Download the repository as a ZIP from GitHub and extract the folder.
2. In Unity Hub, use **Projects → Add/Open** and choose the extracted repository folder (the folder that contains `Assets`, `Packages`, and `ProjectSettings`).
3. Open with Unity 6.6 and wait for Unity Package Manager to finish.
4. In Unity's top menu, choose **Steal Eggs → Build Demo Arena**.
5. Press the **Play** triangle to test.

## Controls
- **W/A/S/D** or arrow keys: move
- **E**: pick up the nearest egg
- Walk back to the blue base to bank carried eggs

## Prototype includes
- Automatically generated simple 3D arena, bases, eggs, player, rival bot and HUD
- Keyboard movement, collecting eggs and scoring at base
- Computer-controlled rival that competes for eggs

## Not implemented yet
- Online multiplayer
- Shop and upgrades
- Saved progression
- Mobile touch controls
- Final character/egg art
- A verified CrazyGames Web build

Unity does not need to be directly connected to GitHub to run the project. GitHub stores the source; Unity opens, runs, and builds the game locally.
